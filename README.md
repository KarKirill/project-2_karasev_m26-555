# Примитивная база данных

Консольное приложение на **Python 3.12** для управления таблицами с сохранением их структуры в JSON-файл.

Проект создаётся с помощью **uv**. На текущем этапе реализованы создание, просмотр и удаление таблиц, проверка пользовательского ввода и сохранение метаданных между запусками программы.

## Возможности

- Создание таблиц со столбцами типов `int`, `str`, `bool`.
- Автоматическое добавление столбца `ID:int`.
- Просмотр списка существующих таблиц.
- Удаление таблиц.
- Проверка существования таблицы, корректности имён, формата и типов столбцов.
- Сохранение структуры таблиц в `db_meta.json`.
- Интерактивное управление через команды `help` и `exit`.

> **Текущая версия:** управление таблицами. Операции с записями (`insert`, `select`, `update`, `delete`) будут добавлены на следующем этапе.

## Требования

- Python 3.12;
- [uv](https://docs.astral.sh/uv/getting-started/installation/);
- Git (для клонирования проекта).

## Установка

Клонируйте **свой** репозиторий GitLab и перейдите в его папку:

```bash
git clone <URL_репозитория>
cd <папка_репозитория>
```

Установите зависимости и пакет:

```bash
uv sync
```

Основные зависимости: `prompt` (консольный ввод), `prettytable` (подготовлена для следующего этапа). Для разработки используется `ruff`.

## Запуск

Из корневой папки проекта:

```bash
uv run database
```

Для просмотра доступных команд в работающем приложении введите `help`, для завершения — `exit`.

## Управление таблицами

| Команда | Описание |
| --- | --- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать все таблицы |
| `drop_table <имя>` | Удалить таблицу |
| `help` | Вывести справку |
| `exit` | Выйти из программы |

Поддерживаемые типы столбцов: **`int`**, **`str`**, **`bool`**.

Столбец `ID:int` добавляется автоматически — указывать его в команде не нужно. Имена столбцов в одной таблице должны быть уникальными.

### Пример работы

```text
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: list_tables
- users

Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

Введите команду: create_table products price:float
Некорректное значение: float. Попробуйте снова.

Введите команду: drop_table users
Таблица "users" успешно удалена.

Введите команду: list_tables
Таблиц пока нет.

Введите команду: exit
Завершение работы.
```

## Хранение данных

Структуры таблиц сохраняются в файл **`db_meta.json`** в текущей рабочей директории. Пример содержимого после создания `users`:

```json
{
    "users": {
        "ID": "int",
        "name": "str",
        "age": "int",
        "is_active": "bool"
    }
}
```

Файл создаётся при первом успешном сохранении и исключён из Git через `.gitignore`. На следующем этапе записи таблиц будут храниться отдельно в `data/`.

## Структура проекта

```text

    ├── main.py         # Точка входа
    ├── engine.py       # Цикл программы и обработка команд
    ├── core.py         # Создание, просмотр и удаление таблиц
    ├── utils.py        # Загрузка и сохранение JSON
    └── constants.py    # Общие константы
```
